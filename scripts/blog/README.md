# ブログを書く道具（GitHub Actions 版）

Mac が眠っていても記事が出るように、ここに置いています（2026-09-02）。

- `blog.py` … 記事を1本書いて、PRを作って、そのままマージします
- `heroimg.py` … トップ画像を作ります
- `狙い.txt` … **どのサービス×地域を狙うか。中元さんが自由に書き換えられます**

## 狙いの書き方

上から順に1本ずつ書き、いちばん下まで行ったらまた上に戻ります。
**同じ行を何度も書くほど、そこに記事が集まります。**

```
家具組立:富士市
物置組立:富士市
```

`#` で始まる行と空の行は無視します。

## Mac 側との関係

**2026-09-02、こちらが本番になりました。** 毎日10時（日本時間）に動きます。
**Mac が眠っていても、電源が落ちていても記事は出ます。**

Mac の `~/.fukkaru/autoupload.sh` からは `blog` を外してあります。
`~/.fukkaru/blog.py` は残っていますが、走りません。
**両方動かすと1日に2本出ます。戻すときは必ず両方を同時に。**

記事を書いた記録は `state/_ログ.txt` に残り、記事と一緒にコミットされます。
Mac が5分おきにリポジトリを引いて、管制画面にブログの様子を映します。
